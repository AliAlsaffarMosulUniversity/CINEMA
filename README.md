# CINEMA | سينما

تطبيق ويب عربي للأفلام بتصميم أسود وذهبي، مع البحث والتصنيفات والمفضلة وسجل المشاهدة وإضافة أفلام بروابط مباشرة.

## التشغيل

افتح `index.html` مباشرة أو شغّل `python -m http.server 8080` من مجلد المشروع ثم افتح http://localhost:8080 . جميع فيديوهات البداية مرفقة محليًا ولا تحتاج رابط النسخة الخاصة لتشغيلها.

النسخة المنشورة الخاصة: https://saffar-cinema.nutmegwhale34.chatgpt.site
